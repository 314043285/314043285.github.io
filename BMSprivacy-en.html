## 1\. Introduction This Privacy Policy applies to the **BMS Config Tool** mobile application\. This app is a professional battery monitoring and debugging tool for BMS hardware devices\. This application **does NOT collect, store, or transmit any personal user privacy data**\. ## 2\. Data We Collect \(Only Device Technical Data\) The app only reads battery operating data from your BMS hardware via Bluetooth, including: - Battery voltage, current, charge/discharge status - Cell temperature, cell voltage difference, SOC - Balance status and protection status - Device serial number \(SN\) ### NO personal data is collected: - No name, phone number, ID card information - No location, photo, camera, microphone, contacts - No device ID, advertising ID - **Server does NOT record user IP address** - No personally identifiable information \(PII\) is collected ## 3\. Purpose of Data Usage All collected data is **only used for**: 1. Real\-time battery status monitoring 2. Battery fault diagnosis and debugging 3. Cloud data storage and device maintenance 4. Equipment operating record tracing We will **never** use data for advertising, marketing, user profiling, or third\-party sharing\. ## 4\. Data Storage \& Security 1. All data collected is anonymous device technical data and has no connection to any individual user identity\. 2. All network transmission uses HTTPS encryption\. 3. Server does not log user IP addresses\. 4. No user private data is stored\. ## 5\. Third\-Party Sharing We **do not share, sell, or rent any data** to third parties\. ## 6\. Permission Usage This app only uses Bluetooth permission for device connection\. No privacy\-sensitive permissions are required\. ## 7\. Children’s Privacy This app is a professional industrial debugging tool and is not intended for minors\. ## 8\. Policy Updates We may update this privacy policy when necessary\. Updates will be published within the app\. ## 9\. Contact If you have any privacy questions, please contact the developer\.
